# mod_robosim — симулятор RoboSim для Moodle

Элемент курса: ученик собирает схему Arduino/Raspberry Pi, пишет скетч,
проходит автопроверку задания и сдаёт работу; оценка попадает в журнал.

Сам симулятор лежит в каталоге `simulator/` — интернет не нужен.

* Установка и описание: `README.md` в корне ветки `moodle`.
* Данные примеров и заданий: `examples.json`, `tasks.json`
  (обновляются скриптами из `tools/`).
* Требуется Moodle 4.0+.
